# 四级备考规划师 · 可交互学习应用（网页版）

一个**纯前端单页应用**：注册建档、四阶段导航、查看计划、资料库（已核实官方链接）、技巧库、打卡、错题、模考分数、一键导出 Markdown 档案。所有数据保存在浏览器 `localStorage`，多学员档案相互独立、互不干扰。

## 文件构成
```
web/
├── index.html   # 页面结构
├── styles.css   # 样式（含移动端响应式）
├── data.js      # 数据层：四阶段·两套每日计划表·官方资源库·高分技巧库
└── app.js       # 逻辑层：注册登录·建档·导航渲染·打卡错题模考·档案导出·快捷指令
```

## 打开方式
- **方式一（最简单）**：直接双击 `index.html`（Chrome/Edge）。个别浏览器对 `file://` 下的本地存储有限制，若功能异常请用方式二。
- **方式二（推荐，已本地验证）**：在本目录启动一个静态服务器后访问。
  ```powershell
  # 任选其一
  python -m http.server 4599
  npx --yes serve -l 4599 .
  ```
  然后浏览器打开 http://localhost:4599

## 使用流程
1. 输入「姓名 + 专属密码」→ 注册并建档（老学员点登录即恢复历史档案）
2. 填写 4 项信息：当前基础 / 备考剩余时长 / 每日学习时长 / 最薄弱题型
3. 系统按适配规则自动生成专属计划（基础很差→4个月基础版；基础一般且≤2个月→2个月冲刺版）
4. 左侧导航切换：首页 / 备考计划 / 资料库 / 技巧库 / 学习记录 / 我的档案
5. 顶部快捷指令或胶囊按钮：`查看计划` `查看档案` `听力资料` `阅读资料` `写作资料` `技巧汇总` `单词推荐`
6. 「我的档案」页可**一键复制 / 下载 .md**，直接上传阿里魔搭创空间知识库

## 部署到 QoDer / 魔搭创空间
- 本目录为静态网页，可整包上传到魔搭创空间「静态页面 / 网页应用」直接托管。
